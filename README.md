# Stationery Store

A responsive stationery catalogue and shopping cart built with HTML, CSS and vanilla JavaScript.

## Features

- Product search, availability filtering and price sorting
- Shopping cart with quantity controls and item removal
- Cart persistence using localStorage
- Validation of saved cart data
- Responsive layouts for desktop and mobile
- Keyboard focus restoration after cart updates
- Removal animation with reduced-motion support
- Demo order summary

## Run locally

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Start Live Server for `index.html`.

No build step or package installation is required.

## Demo limitations

Products come from a fixed local dataset. Cart data is stored in the current browser.

The order summary is a demonstration only. No order is submitted and no payment is taken.

## Technologies

HTML, CSS, JavaScript ES modules, localStorage and the native HTML dialog element.
